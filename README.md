# AI Drug Info - زانیاری دەرمان بە ژیریی دەستکرد

ماڵپەڕێکی دروستکراو بە ژیریی دەستکرد (Gemini API) بۆ دەستنیشانکردنی زانیاری دەرمانەکان بە سێ زمانی (کوردی، عەرەبی، ئینگلیزی).

## 🌟 تایبەتمەندییەکان (Features)
- 🔍 **گەڕان بە ناوی دەرمان:** وەرگرتنی زانیاری و وردەکاری بڕی ژەم، زیانە لاوەکییەکان و کارلێکەکان.
- 📷 **پشکنین بە وێنە و کامێرا:** توانای بارکردنی وێنەی غیلافی دەرمان یان گرتنی وێنە ڕاستەوخۆ بە کامێرا.
- 🌐 **پشتیوانی سێ زمان:** (کوردی، العربية، English).

## 🛠️ تەکنەلۆژیاکان (Technologies Used)
- HTML5 / CSS3 / JavaScript (ES6+)
- Google Gemini 1.5 Flash API
